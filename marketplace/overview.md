# XoCrazy — pick your colors, see them instantly

Visual Studio's **Fonts and Colors** dialog is a 400-item list, an OK button, and a restart
before you know whether you liked the change. XoCrazy replaces that loop with a tool window:
click a color, the editor repaints under the cursor. No dialog, no round trip.

Nothing else in the Marketplace does this. Every other theme extension ships *someone else's*
theme and asks you to live in it. XoCrazy ships no theme at all — it hands the colors to you.

---

## What it does

- **Live apply.** Colors land on the open editor as you pick them. Nothing to confirm.
- **Point at what you want to change.** Put the caret on a token and XoCrazy tells you which
  classification actually paints it — no guessing which of the 400 entries is "the comment one".
- **Undo that works.** Full edit history, so experimenting costs nothing.
- **Presets.** Start from a preset, then bend every color to taste.
- **Your theme stays yours.** Changes are written to the standard Fonts and Colors store, so
  they survive uninstall and travel with your VS profile.

## Install

Requires Visual Studio 2022 or later (17.0+), 64-bit, with the core editor workload.

After install: **View → Other Windows → XoCrazy - Live Colors**.
